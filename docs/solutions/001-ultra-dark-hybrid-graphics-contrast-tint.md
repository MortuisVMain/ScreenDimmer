# Решение: Сверхтемнота ниже минимума на гибридной графике Windows 11 (DWM + DDC/CI + Transparent Overlay)

## Проблема
При попытке программно понизить яркость экрана ниже аппаратного минимума (0%) с помощью вызова Win32 API `SetDeviceGammaRamp` на современных системах с Windows 11 и гибридной графикой (Intel UHD / Iris Xe + NVIDIA Optimus):
- `SetDeviceGammaRamp` возвращает `False` (с кодом ошибки `0`), либо полностью игнорируется композитором рабочего стола DWM.
- В результате экран при затемнении до 0% и «сверхтемноте» оставался одинаковым — никакой дополнительной темноты не появлялось.

## Причина
В архитектуре Windows 11 DWM (Desktop Window Manager) монопольно управляет цветовой калибровкой и гаммой рабочего стола для предотвращения мерцания при переключении между встроенным GPU и дискретным GPU. Прямые вызовы GDI `SetDeviceGammaRamp` блокируются или переопределяются DWM.

## Решение: Двухуровневая архитектура сверхтемноты

1. **Аппаратное подавление контрастности DDC/CI (Внешние мониторы)**:
   - Через `dxva2.dll` вызываются `GetMonitorContrast` и `SetMonitorContrast`.
   - В нормальном режиме контрастность монитора составляет 70–80%.
   - В режиме `Ultra-Dark` аппаратная контрастность сбрасывается до 15%, физически отсекая избыточное свечение матрицы и белых элементов.
   - При выходе контрастность возвращается к исходному сохраненному значению.

2. **Сквозной светофильтр со 100% кликабельностью (Все мониторы, включая ноутбук)**:
   - Полноэкранная форма `UltraDarkOverlayForm` с черным фоном (`Color.Black`).
   - Стили окна:
     ```csharp
     // 0x20 = WS_EX_TRANSPARENT (мышь и клики свободно проходят сквозь форму)
     // 0x80 = WS_EX_TOOLWINDOW (скрыто из Alt+Tab)
     // 0x08 = WS_EX_TOPMOST (поверх всех окон)
     // 0x08000000 = WS_EX_NOACTIVATE (не отбирает фокус)
     cp.ExStyle |= 0x20 | 0x80 | 0x08 | 0x08000000;
     ```
   - Прозрачность по умолчанию: 55% (настраивается слайдером от 20% до 90% в настройках).
   - Плавная анимация fade-in / fade-out через `Task.Delay`.
   - Пользователь может продолжать печатать, играть, смотреть видео и кликать мышью сквозь фильтр.

3. **Горячие клавиши**:
   - `Alt + ;` — активация Сверхтемноты (аппаратный скан-код `0x27` / `VK_OEM_1`).
   - `Alt + '` — деактивация и моментальный возврат к сохраненным ранее настройкам яркости и контрастности (аппаратный скан-код `0x28` / `VK_OEM_7`).
